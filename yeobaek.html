이 방침은 광고와 앱 내 결제가 포함되지 않은 현재 테스트 버전의 처리 방식을 설명합니다. 결제 기능이나 데이터 처리 방식이 달라지면 실제 기능 제공 전에 방침과 앱 안내를 함께 갱신합니다.

1. 사진 분석과 기기 내 정보

운영자 Dr. Sungworld는 여백의 사진·동영상 비교, 정리 후보 제안, 앨범 구성과 압축 기능을 제공합니다. 사진 AI는 기기 안에서 실행하며 사진을 클라우드 AI로 자동 전송하지 않습니다. 현재 앱에는 자체 회원가입이나 개발자 운영 서버를 통한 데이터 수집 기능, 광고 SDK가 없습니다.

허용한 사진·동영상과 촬영일 등 파일 정보, 분석 결과, 보관·보류·정리·복원 이력, 앨범 구성, 압축 작업 상태와 설정을 해당 기능에 이용합니다. 분석 결과와 내부 기록은 앱의 기기 내 저장소에서 관리합니다. 모델 파일은 기기 내 분석을 위한 공개 AI 모델이며 사용자 사진이나 문자가 아닙니다.

2. 선택 권한과 부가 기능

사진과 동영상은 Android에서 사용자가 허용한 범위에서 읽습니다. 미디어 관리 접근은 사용자가 확인한 정리·휴지통·복원 작업에 이용하며 원본에 영향을 주는 작업은 앱의 확인 절차를 거칩니다. 알림 권한은 작업 진행이나 추천 안내에 사용합니다.

현재 앱에는 사용자가 별도로 연결하는 문자 앱 알림 분석, 일정과 기기 내 음성 입력 기능도 포함되어 있습니다.

  • 알림 접근을 허용하고 대상 문자 앱을 선택한 경우 해당 앱의 알림에 표시되는 발신 표시·내용·수신 시각을 로컬 분석에 사용합니다. 문자 원문을 직접 조회하거나 문자를 자동 발신하는 권한은 요청하지 않습니다.
  • 일정 기능을 사용할 때 허용된 캘린더를 조회하고 사용자가 확인한 일정을 선택한 캘린더에 등록합니다.
  • 음성 입력은 사용자가 누르고 말할 때 기기의 온디바이스 인식기를 사용합니다. 사용할 수 없으면 텍스트 입력을 안내하며 클라우드 인식으로 자동 전환하지 않습니다.

권한이나 선택 기능을 사용하지 않으면 관련 기능이 제한될 수 있습니다. 기기의 캘린더 계정, 갤러리 동기화, 외부 앱에 직접 넘기는 정보 등은 해당 운영체제·계정·서비스의 설정과 개인정보처리방침도 적용됩니다. 여백의 로컬 처리 설명이 다른 서비스의 동기화까지 차단한다는 뜻은 아닙니다.

3. 보관, 보호와 삭제

앱 내부 기록은 Android Keystore를 이용한 암호화 저장소에 보관하고 일반 앱 백업에서 제외하도록 설정합니다. 필요한 로컬 기록을 관리하는 동안에도 사용자는 Android 설정에서 앱 데이터를 지우거나 앱을 제거할 수 있습니다. 일부 알림 기록에는 앱의 자동 보관 기간 정리가 적용됩니다.

권한은 Android 설정에서 철회할 수 있습니다. 알림 접근을 철회하면 관련 알림 분석 작업을 중단하고 앱에 저장된 알림 접근 기반 메시지 기록을 제거하도록 처리합니다. 운영체제의 연결 해제 알림과 앱 상태에 따라 처리가 완료되는 시점은 달라질 수 있습니다.

사진·영상 원본, 압축본, 갤러리에 만든 앨범과 캘린더에 등록한 일정은 앱의 내부 기록과 별개입니다. 앱 제거만으로 이 항목들이 모두 삭제되지는 않습니다. 압축본을 만들어도 원본을 바로 지우지 않으며 원본의 휴지통 이동은 별도로 확인합니다. 휴지통 보관·복원·자동 삭제에는 Android와 기기 미디어 서비스의 정책도 적용됩니다.

기기 내 암호화와 접근 제한을 사용하지만 모든 기기와 사용 환경에서 절대적인 보안을 보장할 수는 없습니다. 중요한 원본은 사용자가 별도로 보관해 주세요.

4. 외부 서비스와 변경

앱을 내려받거나 Google Play를 이용할 때 Google은 해당 서비스의 정책에 따라 정보를 처리할 수 있습니다. 이 웹페이지는 GitHub Pages에 게시되어 있어 웹사이트 접속 정보는 GitHub의 정책에 따라 처리될 수 있습니다. 이 페이지에는 별도의 광고·분석 스크립트를 넣지 않았습니다.

현재 테스트 버전에는 앱 내 결제가 없습니다. 향후 한 번 결제로 유료 기능을 해제하는 기능을 제공할 경우 구매·복원·검증에 필요한 처리와 Google Play 또는 검증 서비스의 역할을 실제 구현에 맞춰 추가 안내합니다. 사진·문자·일정 내용을 구매 검증에 사용하도록 설계하지 않습니다.

앱 기능, 외부 서비스 또는 법적 요구가 달라지면 이 페이지의 내용과 갱신일을 변경합니다.
